# ScamGuard AI

ScamGuard AI เป็น Web Application ที่พัฒนาขึ้นเพื่อช่วยผู้ใช้งาน
วิเคราะห์ข้อความที่น่าสงสัยและประเมินความเสี่ยงจากการหลอกลวงออนไลน์

ระบบประยุกต์ใช้ Machine Learning, Natural Language Processing (NLP)
และ Retrieval-Augmented Generation (RAG)
เพื่อช่วยวิเคราะห์รูปแบบของข้อความและอธิบายผลลัพธ์
ให้อยู่ในรูปแบบที่ผู้ใช้งานทั่วไปสามารถเข้าใจได้ง่าย

---

## Problem

ปัจจุบันการหลอกลวงออนไลน์สามารถเกิดขึ้นได้จากหลายช่องทาง
เช่น SMS, LINE, Email หรือลิงก์ที่ไม่น่าเชื่อถือ

ผู้ใช้งานทั่วไปอาจไม่สามารถประเมินได้ทันทีว่า
ข้อความที่ได้รับมีความเสี่ยงหรือเข้าข่ายมิจฉาชีพหรือไม่

---

## Solution

ScamGuard AI ถูกออกแบบมาเพื่อช่วยวิเคราะห์ข้อความที่ผู้ใช้สงสัย
และตรวจหารูปแบบที่อาจเกี่ยวข้องกับการหลอกลวง

ระบบใช้ Machine Learning และ NLP ในการวิเคราะห์ข้อความ
ร่วมกับ RAG และ AI เพื่อช่วยอธิบายเหตุผลของความเสี่ยง
ให้ผู้ใช้งานสามารถเข้าใจและตัดสินใจได้ง่ายขึ้น

---

## Features

- วิเคราะห์ข้อความที่น่าสงสัย
- ตรวจจับรูปแบบข้อความด้วย NLP
- Machine Learning Classification
- ตรวจสอบลิงก์ที่อาจมีความเสี่ยง
- ตรวจสอบข้อมูลหมายเลขโทรศัพท์
- ใช้ RAG เพื่อค้นคืนข้อมูลประกอบการวิเคราะห์
- AI Assistant สำหรับอธิบายความเสี่ยง
- Web Chat Interface สำหรับผู้ใช้งาน

---

## My Role

ได้มีส่วนร่วมในการออกแบบแนวคิดและโครงสร้างการทำงานของระบบ
รวมถึงการประยุกต์ใช้ Machine Learning, NLP, RAG และ LLM
เพื่อช่วยให้ระบบสามารถวิเคราะห์ข้อความ
และอธิบายความเสี่ยงในรูปแบบที่เข้าใจง่าย

โปรเจกต์นี้ทำให้ฉันได้เรียนรู้การนำ AI
มาประยุกต์ใช้กับปัญหาที่เกิดขึ้นในชีวิตประจำวัน
และการออกแบบระบบที่ไม่ได้เพียงแสดงผลการวิเคราะห์
แต่ต้องสามารถอธิบายผลลัพธ์ให้ผู้ใช้งานเข้าใจได้ด้วย
